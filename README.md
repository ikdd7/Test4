# 🔥 소방 법령 RAG 안내 챗봇

대한민국 **소방시설 설치 및 관리에 관한 법률** / **화재의 예방 및 안전관리에 관한 법률**(각 시행령·시행규칙·별표·고시·질의회신·법령해석)의 **근거 조문을 정확히 찾아 보여주는** 웹 도구입니다.

> ⚖️ **본 도구는 법령 정보 안내이며 법률 자문이 아닙니다.** 최종 판단은 원문 확인 및 관할 소방서·전문가 확인을 거치세요.

---

## 0. 한눈에 보기

- **프론트(브라우저 채팅) + 서버(API 라우트)** 구조. **API 키는 서버에서만** 사용 — 프론트에 절대 노출되지 않습니다.
- 답변 생성: **Anthropic Claude API**(`claude-opus-4-8`, 정확성 우선).
- 의미검색 임베딩: **무료 오픈소스 한국어(다국어) 모델 `Xenova/multilingual-e5-small`** (Transformers.js, 로컬 실행) → **당신이 발급할 키는 Claude 키 하나뿐**.
- 검색: **하이브리드(키워드 + 벡터)**, 법률·시행령·규칙·별표·고시·질의회신을 **계층 가로질러** 검색.
- 답변: **효력 위계 구분**(①법령 근거 / ②해석·참고) + **4중 환각 억제** + **건물 조건 판정 규칙** + **근거 표기**.
- 배포: **Vercel** 무료 등급으로 가능. 접속은 **비밀번호**로 보호.

## 2. 데이터 넣기 (가장 중요)

`./data` 의 **종류별 하위폴더**에 `.txt`(또는 `.md`) 파일을 넣습니다.
**인터넷에서 크롤링하지 마세요. 반드시 ./data 파일만 근거로 사용합니다.** (국가법령정보센터에서 원문을 받아 텍스트로 저장)

각 파일 맨 위에 **프론트매터(메타데이터)** 를 붙이면 인용 정확도가 올라갑니다(선택이지만 권장):

```
---
법령명: 소방시설 설치 및 관리에 관한 법률 시행령
시행일: 2024.12.01
상위법: 소방시설 설치 및 관리에 관한 법률 제12조
---
(본문: 제11조 …  제12조 …)
```

- **질의회신** 파일: `회신번호`, `회신일자`, `제목` 을 프론트매터로. 한 파일에 여러 건이면 건과 건 사이를 `===` 줄로 구분.
- **자동 청킹 규칙:** 법률/시행령/규칙/고시 = `제○조` 단위, 별표 = `별표 N` 단위, 질의회신 = 회신 건별.
- 폴더에 넣어둔 `*_예시.txt` 는 **동작 확인용 샘플**입니다 — **반드시 실제 원문으로 교체**하세요.

## 3. 로컬에서 실행

### ✋ 여기서 당신이 할 일
1. **Node.js 20+** 설치.
2. 의존성 설치:
   ```bash
   npm install
   ```
3. 환경변수 파일 만들기 — `.env.example` 를 복사해 `.env.local` 생성 후 값 입력:
   ```bash
   cp .env.example .env.local
   ```
   | 변수 | 어디서 구하나 | 비고 |
   |---|---|---|
   | `ANTHROPIC_API_KEY` | https://console.anthropic.com → API Keys → Create Key | **유일한 발급 키** |
   | `APP_PASSWORD` | 직접 정함 | 접속 비밀번호 |
   | `AUTH_SALT` | 아무 랜덤 문자열 | 쿠키 서명용(권장) |
   | `ANTHROPIC_MODEL` | (선택) | 기본 `claude-opus-4-8` |
4. **인제스트(색인 생성)** — `./data` 에 파일을 넣은 뒤:
   ```bash
   npm run ingest
   ```
   → `data/index.json` 이 생성됩니다. (임베딩 모델 최초 1회 자동 다운로드)
5. 개발 서버:
   ```bash
   npm run dev
   ```
   → 브라우저 `http://localhost:3000` → 비밀번호 입력 → 질문.

> 데이터를 추가/수정할 때마다 **`npm run ingest` 를 다시 실행**하고 `data/index.json` 을 커밋하세요.

## 4. Vercel 배포 (클릭 단위)

> 전제: 이 폴더를 GitHub 저장소에 푸시해 둡니다. `data/index.json` 도 **반드시 커밋**되어 있어야 합니다(런타임 검색이 이 파일을 읽음).

1. https://vercel.com 가입/로그인 → **Add New… → Project**.
2. **Import Git Repository** 에서 이 저장소 선택 → **Import**.
3. **Framework Preset** 가 `Next.js` 로 자동 인식되는지 확인(그대로 둠).
4. **Environment Variables** 펼치고 아래를 추가(Name / Value):
   - `ANTHROPIC_API_KEY` = (당신의 Claude 키)
   - `APP_PASSWORD` = (접속 비밀번호)
   - `AUTH_SALT` = (아무 랜덤 문자열)
   - (선택) `ANTHROPIC_MODEL` = `claude-opus-4-8`
5. **Deploy** 클릭 → 빌드 완료까지 대기.
6. 발급된 주소(`https://…vercel.app`) 접속 → 비밀번호 입력 → 사용.
7. 이후 데이터 갱신: 로컬에서 `npm run ingest` → `git commit` → `git push` 하면 자동 재배포됩니다.

> ⏱️ 첫 질문은 임베딩 모델을 서버가 처음 로드하느라 **수 초 느릴 수 있습니다**(콜드 스타트). 이후 요청은 빨라집니다.

## 5. 벡터DB는 왜 외부 DB를 안 쓰나 / 확장 경로

- **기본:** 외부 벡터DB 없이 **파일 인덱스(`data/index.json`) + 인메모리 검색**.
  - *이유:* 대상 코퍼스가 한정적(2개 법령 체계)이라 수백~수천 청크 → 인메모리 코사인+키워드로 충분하고, **추가 키·가입이 전혀 없어** "Claude 키 하나" 원칙을 지킵니다. 무료입니다.
- **나중에 자료가 매우 커지면(수만 청크↑)** 무료 등급 벡터DB로 확장 가능:
  - **Upstash Vector** — 무료 등급, 하이브리드(밀집+희소) 지원, 서버리스 친화. *임베딩 내장 옵션도 있어 운영이 단순.*
  - **Supabase(pgvector)** — 무료 등급, SQL + 벡터 + 전문검색을 한곳에서.
  - 두 경우 모두 해당 서비스의 접속 정보(무료)가 추가됩니다. 필요해질 때 `lib/search.ts` 만 교체하면 됩니다.

## 6. 정확성·안전 설계 요약

- **효력 위계:** ①[법령 근거](법률·시행령·규칙·별표·고시=구속력) / ②[해석·참고](질의회신·법령해석=공식 해석, "○○년 기준·개정 가능" 표시).
- **4중 환각 억제:** ①검색자료만 근거(없으면 "검색된 자료에 없습니다") ②[조문 원문]과 [쉬운 설명] 분리 ③표·별표는 표 전체/구간 함께 제시 ④수치 경계(이상/초과/미만/이하) 원문 그대로.
- **건물 조건 판정:** 용도분류 후보 → 별표·조문 원문 → 입력 대입 "잠정 결과"(조건·예외·단서 분해) → "자동 대입, 최종 확인 필요" 경고(복합용도·소급·단서 명시).
- **면책:** 화면 하단·첫 안내에 고정 표시, 답변 끝에도 표기.

## 7. 테스트용 질문 10개

> 아래는 동봉된 **예시 데이터** 기준입니다. 실제 원문으로 교체하면 그에 맞게 동작합니다.

**A. 단순 조문 조회형**
1. 소방시설법 **제12조** 원문 보여줘.
2. 소방시설기준 적용의 특례(**제13조**)에서 강화된 기준을 적용하는 설비는 뭐야?
3. 화재예방법에서 **소방안전관리자**를 두어야 하는 대상의 근거 조문 알려줘.
4. 스프링클러설비 **화재안전성능기준상 헤드 수평거리** 기준 원문은?

**B. 별표 수치 조회형**
5. **별표 4**에서 스프링클러설비 설치대상 중 "판매시설" 기준 수치를 표 그대로 보여줘.
6. 자동화재탐지설비는 연면적 **몇 ㎡ 이상**부터 설치대상이야? (경계 표현 그대로)
7. 6층 이상이면 스프링클러를 어느 층에 설치해야 한다고 별표에 적혀 있어?

**C. 건물 조건 판정형**
8. **11층, 업무시설, 연면적 8,000㎡** 건물인데 스프링클러설비 설치 대상인가요?
9. **판매시설 + 업무시설이 같이 있는 복합건축물**인데 스프링클러 설치대상은 어떻게 판단해?
10. **2010년에 지은 기존 건축물**인데 강화된 화재안전기준이 소급 적용되나요?
