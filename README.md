# 🔥 소방 법령 RAG 안내 챗봇

대한민국 **소방시설 설치 및 관리에 관한 법률** / **화재의 예방 및 안전관리에 관한 법률**(각 시행령·시행규칙·별표·고시·질의회신·법령해석)의 **근거 조문을 정확히 찾아 보여주는** 웹 도구입니다.

> ⚖️ **본 도구는 법령 정보 안내이며 법률 자문이 아닙니다.** 최종 판단은 원문 확인 및 관할 소방서·전문가 확인을 거치세요.

## 0. 한눈에 보기

- **프론트(브라우저 채팅) + 서버(API 라우트)** 구조. **API 키는 서버에서만** 사용 — 프론트에 절대 노출되지 않습니다.
- 답변 생성: **Anthropic Claude API**(`claude-fable-5` — Anthropic 최상위 모델, 정확성 최우선. 입력 $10/출력 $50 per 1M tokens. 비용을 낮추려면 env에서 `claude-opus-4-8` 등으로 교체 가능).
- 의미검색 임베딩: **무료 오픈소스 한국어(다국어) 모델 `Xenova/multilingual-e5-small`** (Transformers.js, 로컬 실행) → **당신이 발급할 키는 Claude 키 하나뿐**.
- 검색: **하이브리드(키워드 + 벡터)**, 법률·시행령·규칙·별표·고시·질의회신을 **계층 가로질러** 검색.
- 답변: **효력 위계 구분**(①법령 근거 / ②해석·참고) + **4중 환각 억제** + **건물 조건 판정 규칙** + **근거 표기**.
- 배포: **Vercel** 무료 등급으로 가능. 접속은 **비밀번호**로 보호.

## 🧪 API 없이 무료로 테스트하기 (검색 전용 모드)

Claude API 키 없이도 바로 써볼 수 있습니다. **API 키를 넣지 않으면** 자동으로 **검색 전용 모드**로 동작합니다(또는 `LLM_MODE=search` 설정).
- 질문하면 LLM 해석 없이 **매칭된 조문·별표 원문을 효력 위계대로 그대로** 보여줍니다. **환각 0(원문 그대로) · 비용 0.**
- 동봉된 `data/index.json` 덕분에 **인제스트도 필요 없습니다.**

**로컬에서 바로 (3단계):**
```bash
npm install
echo "APP_PASSWORD=test" > .env.local      # Claude 키 불필요!
npm run dev
```
→ `http://localhost:3000` 접속 → 비밀번호 `test` → 질문 (예: "별표 4 보여줘", "소방시설법 제13조", "과태료 부과기준").

### LLM 답변까지 무료로 — Gemini(권장 테스트)
LLM 해석·판정 답변을 **무료로** 보고 싶으면 **Google Gemini 무료 키**를 쓰면 됩니다.
1. https://aistudio.google.com → **Get API key**(무료) 발급
2. `.env.local`(또는 Vercel 환경변수)에 `GEMINI_API_KEY=발급키` 추가 → **자동으로 Gemini 모드**로 전환(검색→근거주입→생성→검증).
3. 모델이 안 맞으면 `GEMINI_MODEL=gemini-2.0-flash`(또는 `gemini-1.5-flash`)로 바꾸세요.

**공급자는 키만 넣으면 자동 선택**됩니다: `GEMINI_API_KEY` → Gemini · `ANTHROPIC_API_KEY` → Claude(에이전틱+검증, 유료·최상) · 둘 다 없음 → 검색 전용(원문만).

## 2. 데이터 넣기 (가장 중요)

`./data` 폴더에 파일을 넣습니다. **지원 형식: `.hwp`(국가법령정보센터 HWPML·XML) / `.txt` / `.md`.**
**인터넷에서 크롤링하지 마세요. 반드시 ./data 파일만 근거로 사용합니다.**

### 👉 가장 쉬운 방법: `data/inbox/` 에 전부 넣기 (분류 불필요)
파일이 많으면 **종류 구분 없이 `data/inbox/` 한 폴더에 전부** 넣으세요. 인제스트가 각 파일의 제목(`<TITLE>`)을 보고 **법률/시행령/시행규칙/고시/질의회신을 자동 분류**합니다.
```
data/inbox/   ← 받은 .hwp 파일을 여기에 몽땅 드래그
```
- 국가법령정보센터에서 받은 `.hwp`를 그대로 넣으면 됩니다(한글에서 변환 불필요). 자동으로 본문 추출 + 법령명 + 시행일 + 상위법을 인식합니다.

### (대안) 직접 분류해서 넣기
정확히 통제하고 싶으면 종류별 폴더에 직접: 법률→`law`, 시행령→`enforcement_decree`, 시행규칙→`enforcement_rule`, 별도 별표→`appendix`, 고시·화재안전기준→`notice`, 질의회신·법령해석→`interpretation`.

- `.txt/.md`로 넣을 땐 맨 위 프론트매터(`법령명`/`시행일`/`상위법`) 권장.
- **자동 청킹:** 법률/시행령/규칙/고시 = 줄머리의 `제○조`/`별표 N` 단위, 별표폴더 = `별표 N`, 질의회신 = 회신 건별. (법령 본문에 포함된 별표는 자동으로 "별표"로 분리)

### 현재 적재된 자료
✅ **소방시설 설치 및 관리에 관한 법률**(본문·시행령·시행규칙)
✅ **화재의 예방 및 안전관리에 관한 법률**(본문·시행령·시행규칙)
✅ **별표 39종**(과태료·과징금·시설/등록 기준 등 표 전문 — 바이너리 HWP를 텍스트로 변환해 적재)
✅ **고시: 스프링클러설비 화재안전기술기준(NFTC 103)**
✅ **질의회신: 소방청 「소방시설법령 질의회신집」 2021·2022·2024·2025 (1,088건)** — 총 1,487청크.
   (PDF는 `scripts/pdf_qa_to_text.py`로 회신 건별 텍스트 변환 후 적재 — 새 회신집 PDF도 같은 방식)
⚠️ **아직 빠진 자료(추가 권장):** **그 외 화재안전기술기준(NFTC) 고시들**(소화기·자동화재탐지설비 등). 없으면 해당 질문엔 "검색된 자료에 없습니다"로 정직하게 답합니다.
ℹ️ 별지서식(72종)은 법적 효력이 낮아 제외했습니다(원하면 추가 가능).

### HWP 형식 안내 (중요)
국가법령정보센터 `.hwp`는 두 종류입니다:
- **법령 본문/시행령/규칙 = HWPML(XML)** → 인제스트가 직접 읽습니다(그냥 폴더에 넣기).
- **별표·서식 = 바이너리 HWP(.hwp 5.0)** → 인제스트가 못 읽습니다. `pip3 install olefile` 후 `python3 scripts/hwp5_to_text.py 파일.hwp > 별표.txt` 로 변환해 `data/appendix/`(별표)에 넣으세요.

## 3. 로컬에서 실행

### ✋ 여기서 당신이 할 일
1. **Node.js 20+** 설치.
2. 의존성 설치:
   ```bash
   npm install
   ```
3. 환경변수 파일 만들기 — `.env.example` 를 복사해 `.env.local` 생성 후 값 입력:
   ```bash
   cp .env.example .env.local
   ```
   | 변수 | 어디서 구하나 | 비고 |
   |---|---|---|
   | `ANTHROPIC_API_KEY` | https://console.anthropic.com → API Keys → Create Key | **유일한 발급 키** |
   | `APP_PASSWORD` | 직접 정함 | 접속 비밀번호 |
   | `AUTH_SALT` | 아무 랜덤 문자열 | 쿠키 서명용(권장) |
   | `ANTHROPIC_MODEL` | (선택) | 기본 `claude-fable-5` (비용 절감 시 `claude-opus-4-8` 등) |
4. **인제스트(색인 생성)** — `./data` 에 파일을 넣은 뒤:
   ```bash
   npm run ingest
   ```
   → `data/index.json` 이 생성됩니다(임베딩 모델 최초 1회 자동 다운로드).
   - 빠른 점검만 하려면(임베딩 생략, 키워드 검색만): `INGEST_NO_EMBED=1 npm run ingest`
   - **의미검색 품질을 위해 배포 전 반드시 임베딩 포함 인제스트(`npm run ingest`)를 한 번 돌리세요.**
   - 데이터 무결성 점검: `npm run eval` (검색 재현율 측정)
5. 개발 서버:
   ```bash
   npm run dev
   ```
   → 브라우저 `http://localhost:3000` → 비밀번호 입력 → 질문.

> 데이터를 추가/수정할 때마다 **`npm run ingest` 를 다시 실행**하고 `data/index.json` 을 커밋하세요.

## 4. Vercel 배포 (클릭 단위)

> 전제: 이 폴더를 GitHub 저장소에 푸시해 둡니다. `data/index.json` 도 **반드시 커밋**되어 있어야 합니다(런타임 검색이 이 파일을 읽음).

1. https://vercel.com 가입/로그인 → **Add New… → Project**.
2. **Import Git Repository** 에서 이 저장소 선택 → **Import**.
3. **Framework Preset** 가 `Next.js` 로 자동 인식되는지 확인(그대로 둠).
4. **Environment Variables** 펼치고 아래를 추가(Name / Value):
   - `APP_PASSWORD` = (접속 비밀번호) — **필수**
   - `AUTH_SALT` = (아무 랜덤 문자열)
   - **LLM 공급자(하나 선택, 또는 생략):**
     - 무료 테스트 → `GEMINI_API_KEY` = (AI Studio 무료 키), 필요시 `GEMINI_MODEL` = `gemini-2.5-flash`
     - 최상 정확도 → `ANTHROPIC_API_KEY` = (Claude 키), `ANTHROPIC_MODEL` = `claude-fable-5`
     - 생략 → 키 없이 **검색 전용 모드**(원문만)로 배포됨
   - ⚠️ Import 시 **브랜치를 `claude/vibe-coding-business-Y6GCN`** 로 선택하세요(코드가 이 브랜치에 있습니다).
5. **Deploy** 클릭 → 빌드 완료까지 대기.
6. 발급된 주소(`https://…vercel.app`) 접속 → 비밀번호 입력 → 사용.
7. 이후 데이터 갱신: 로컬에서 `npm run ingest` → `git commit` → `git push` 하면 자동 재배포됩니다.

> ⏱️ 첫 질문은 임베딩 모델을 서버가 처음 로드하느라 **수 초 느릴 수 있습니다**(콜드 스타트). 이후 요청은 빨라집니다.

## 5. 벡터DB는 왜 외부 DB를 안 쓰나 / 확장 경로

- **기본:** 외부 벡터DB 없이 **파일 인덱스(`data/index.json`) + 인메모리 검색**.
  - *이유:* 대상 코퍼스가 한정적(2개 법령 체계)이라 수백~수천 청크 → 인메모리 코사인+키워드로 충분하고, **추가 키·가입이 전혀 없어** "Claude 키 하나" 원칙을 지킵니다. 무료입니다.
- **나중에 자료가 매우 커지면(수만 청크↑)** 무료 등급 벡터DB로 확장 가능:
  - **Upstash Vector** — 무료 등급, 하이브리드(밀집+희소) 지원, 서버리스 친화. *임베딩 내장 옵션도 있어 운영이 단순.*
  - **Supabase(pgvector)** — 무료 등급, SQL + 벡터 + 전문검색을 한곳에서.
  - 두 경우 모두 해당 서비스의 접속 정보(무료)가 추가됩니다. 필요해질 때 `lib/search.ts` 만 교체하면 됩니다.

## 6. 정확성·안전 설계 요약

- **효력 위계:** ①[법령 근거](법률·시행령·규칙·별표·고시=구속력) / ②[해석·참고](질의회신·법령해석=공식 해석, "○○년 기준·개정 가능" 표시).
- **4중 환각 억제:** ①검색자료만 근거(없으면 "검색된 자료에 없습니다") ②[조문 원문]과 [쉬운 설명] 분리 ③표·별표는 표 전체/구간 함께 제시 ④수치 경계(이상/초과/미만/이하) 원문 그대로.
- **건물 조건 판정:** 용도분류 후보 → 별표·조문 원문 → 입력 대입 "잠정 결과"(조건·예외·단서 분해) → "자동 대입, 최종 확인 필요" 경고(복합용도·소급·단서 명시).
- **면책:** 화면 하단·첫 안내에 고정 표시, 답변 끝에도 표기.

### 신뢰성 강화 장치 (질문 1건당 자동 수행 — 토큰을 더 쓰더라도 정확도 우선)
1. **정확 조회(`lookup_article`)** — "제13조 / 별표 4"처럼 명시적 참조는 의미검색이 아니라 **키 1:1 조회**로 정확히 반환(확정적). 개념·조건 질문만 의미검색(`search_law`).
2. **에이전틱 다단계 재검색** — 모델이 질문을 분해해 여러 번 조회/검색(법률→시행령→별표→고시→해석)하고, 본문에 나온 "별표 4·법 제12조" 참조 사슬을 끝까지 추적. (단발 검색의 "못 찾아서 틀림" 제거)
3. **동의어·약칭 사전** — 실무용어↔법령용어("스프링쿨러"↔"스프링클러설비") 매칭으로 검색 재현율↑. (`lib/search.ts`의 `SYNONYMS`에서 계속 보강)
4. **검증 패스** — 초안 답변을 검색된 원본 자료와 한 글자씩 대조해 인용·수치·경계표현 불일치를 정정.
5. **인용 verbatim 게이트** — 모델이 원문 인용을 «»로 감싸게 하고, 서버가 «» 안 문장을 원본과 **글자 단위로 대조**. 불일치 시 "⛔ 인용 검증 실패(신뢰 불가)" 명시.
6. **참조 실재 검사** — 답변이 언급한 "제N조/별표 N"이 검색자료에 실재하는지 기계 대조, 없으면 "⚠️ 원문 직접 확인" 경고.

### 회귀 평가 (신뢰성을 "숫자"로 — 데이터/코드 바꿀 때마다 실행)
```bash
npm run eval
```
- `eval/golden.jsonl`(정답셋)으로 **검색 재현율(Recall@12)** 을 측정합니다. (Claude 키 불필요 — 임베딩만 로컬 사용)
- 정답 조문/별표/키워드가 상위에 안 들면 미통과로 표시 → 데이터·동의어·임베딩을 점검하라는 신호.
- 통과율 90% 미만이면 비정상 종료(코드 1) → **CI에서 배포 차단**에 활용 가능.
- ✋ **이 정답셋을 소방 전문가 검수 문항으로 100~300개까지 늘리는 것이 "신뢰도 100%에 가장 가까워지는" 핵심 작업입니다.**

> ⏱️ **중요(Vercel 타임아웃):** 이 파이프라인은 한 질문에 Claude를 여러 번 호출하므로 어려운 질문은 1~2분 걸릴 수 있습니다.
> - **Vercel Hobby(무료)는 함수 실행 60초 상한** → 복잡한 질문에서 시간 초과가 날 수 있습니다.
> - **신뢰성 파이프라인을 온전히 쓰려면 Vercel Pro(300초)를 권장**합니다. 또는 비용/속도를 위해 `app/api/chat/route.ts`의 `MAX_SEARCH_ROUNDS`를 줄이거나(예: 3), `ANTHROPIC_MODEL`을 더 빠른 모델로 바꿀 수 있습니다.

> 정직하게: 이 장치들은 정확도를 **크게 높이지만 100%를 보장하지는 않습니다.** RAG는 넣어준 데이터(원문 정확성·최신성)를 넘을 수 없고, 용도분류·복합용도·소급 같은 *법 해석* 영역은 본 도구가 확정하지 않습니다 — 그래서 "근거 안내" 도구이며 최종 판단은 원문·전문가 확인이 필요합니다.
